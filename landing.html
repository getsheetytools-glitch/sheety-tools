Focus Budget

A visual way to spend your attention on purpose.

Your focus is limited. This makes the tradeoffs visible — so the “top slice” is honest, and everything else is a deliberate choice. No timers. No streaks. No productivity guilt.

How it works

simple by design

1) Add focus items

Add anything that wants your attention — tasks, projects, people, worries, goals. If it competes for mental space, it counts.

2) Rank them

Drag items or use arrows. Higher rank = bigger slice. Moving one up always costs something else.

3) Read the tradeoffs

The pie is a snapshot of reality. Make it honest, then adjust as reality changes.

What the percentages mean: you don’t assign numbers. The tool distributes attention by rank so you can focus on relative importance, not false precision.

What this is (and isn’t)

thinking tool, not a system

It is

A calm way to make priorities visible — especially when everything feels important.

It isn’t

A task manager, time tracker, or productivity framework. No commitments required.

It’s allowed to change

This is a snapshot. You’re allowed to reorder it tomorrow — or in five minutes.

Privacy

local-first

No accounts

There’s nothing to sign up for. It works instantly.

No tracking

No analytics, no telemetry, no quiet data collection.

Your browser only

Data is stored locally via localStorage. Clear site data and it’s gone.
